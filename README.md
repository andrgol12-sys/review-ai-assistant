# 🤖 Review AI Assistant

ИИ-ассистент для обработки и анализа клиентских отзывов интернет-магазина бытовой техники и электроники **HomeTech**.

Проект разработан как учебный проект **PEcf06.2** на основе технического задания, приближенного к реальному заказу.

Ассистент помогает классифицировать отзывы, формировать корректные проекты ответов клиентам, выявлять критические обращения и анализировать группу отзывов.

> HomeTech — вымышленная компания. Все отзывы и данные в проекте являются тестовыми.

---

## 🎯 Задача проекта

Автоматизировать первичную обработку клиентских отзывов и снизить объём ручной работы сотрудников поддержки и маркетинга.

Ассистент решает следующие задачи:

- определяет тональность отзыва;
- классифицирует тип обращения;
- выделяет основные темы;
- оценивает критичность ситуации;
- определяет необходимость эскалации сотруднику;
- формирует проект корректного ответа клиенту;
- анализирует группу отзывов;
- рассчитывает статистику;
- выявляет повторяющиеся проблемы;
- формирует аналитическую сводку и рекомендации.

---

## ⚙️ Возможности

### Анализ одного отзыва

Для отдельного отзыва ассистент формирует структурированный результат:

```text
Тональность: mixed
Тип обращения: mixed
Темы: product, delivery, service
Критичность: medium
Эскалация: no

Основная суть:
...

Рекомендуемое действие:
...

Проект ответа клиенту:
...
```

Ассистент использует системный промпт, правила HomeTech и релевантные записи из базы знаний.

### Анализ нескольких отзывов

Пользователь может последовательно ввести несколько отзывов.

Для каждого отзыва выполняется отдельная классификация, после чего Python рассчитывает общую статистику.

Итоговый отчёт содержит:

1. объём выборки;
2. распределение по тональности;
3. основные темы;
4. повторяющиеся проблемы;
5. положительные тенденции;
6. критические случаи;
7. рекомендации.

## 🧠 Архитектура

Проект использует гибридный подход:

```text
Отзыв клиента
      ↓
Поиск релевантных записей
в CSV-базе знаний
      ↓
OpenAI API
      ↓
Структурированная классификация
      ↓
Бизнес-правила Python
      ↓
Расчёт статистики Python
      ↓
Аналитическая сводка LLM
```

Разделение ответственности позволяет уменьшить вероятность ошибок модели.

### LLM отвечает за

- понимание естественного языка;
- определение тональности;
- классификацию обращения;
- выделение тем;
- краткое описание проблемы;
- генерацию проекта ответа;
- формирование текстовой аналитической сводки.

### Python отвечает за

- применение обязательных бизнес-правил;
- критичность и правила эскалации в ключевых сценариях;
- подсчёт статистики;
- количество отзывов;
- распределение тональности;
- подсчёт тем;
- количество критических случаев;
- количество эскалаций.

Таким образом, LLM не используется для самостоятельного подсчёта количественной статистики.

## 🚨 Бизнес-правила

Для важных ситуаций применяются дополнительные правила на уровне Python.

Примеры:

| Ситуация | Критичность | Эскалация |
|---|---|---|
| Обычная задержка доставки | medium | no |
| Обычная неисправность товара | medium | yes |
| Возврат или обмен | medium | yes |
| Гарантийный вопрос | medium | yes |
| Требование компенсации | high | yes |
| Товар не доставлен | high | yes |
| Опасная неисправность | high | yes |
| Юридическая угроза | high | yes |

Например, отзыв:

```text
Чайник начал искрить и появился запах гари.
```

классифицируется как потенциально опасная ситуация:

```text
Критичность: high
Эскалация: yes
```

При этом ассистент не диагностирует неисправность и рекомендует прекратить использование устройства до выяснения обстоятельств.

База знаний находится в:

```text
data/knowledge_base_hometech.csv
```

Она содержит типовые ситуации и правила обработки отзывов:

- часто встречающиеся формулировки;
- тип обращения;
- тональность;
- темы и подтемы;
- шаблоны ответов;
- рекомендуемые действия;
- необходимость эскалации;
- критичность;
- правила компании;
- примеры аналитики.

Перед обращением к модели выполняется поиск релевантных записей базы знаний по содержанию отзыва.

## 🔐 Ограничения и безопасность

Ассистент не должен:

- самостоятельно публиковать отзывы или ответы;
- удалять сообщения клиентов;
- обещать компенсацию или скидку;
- самостоятельно принимать решение о возврате;
- придумывать статус заказа;
- утверждать, что сотрудник уже выполнил действие;
- диагностировать техническую неисправность;
- придумывать отсутствующий опыт взаимодействия с клиентом;
- без необходимости повторять персональные данные.

Если отзыв содержит персональные данные, ассистент учитывает это при анализе, но не должен воспроизводить их в публичном проекте ответа.

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone <URL-репозитория>
cd review-ai-assistant
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv
```

### 3. Активировать окружение

Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

### 5. Создать `.env`

Пример:

```env
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4.1-mini
```

### 6. Запустить приложение

```bash
python app.py
```

## 💻 Режимы работы

После запуска доступно меню:

```text
1. Обработать один отзыв
2. Проанализировать несколько отзывов
3. Выход
```

### Режим 1

Позволяет обработать отдельный отзыв и получить:

- классификацию;
- основную суть;
- рекомендуемое действие;
- проект ответа клиенту.

### Режим 2

Позволяет ввести несколько отзывов и получить итоговую аналитическую сводку.

Для завершения ввода достаточно оставить очередную строку пустой и нажать Enter.

## 🧪 Тестирование

В проекте предусмотрены два уровня автоматической проверки.

### Тестирование отдельных сценариев

```bash
python tests/test_assistant.py
```

Проверяются:

1. опасная неисправность;
2. смешанный отзыв;
3. требование компенсации;
4. неясная жалоба;
5. отзыв с персональными данными.

Текущий результат:

```text
Результат: 5/5 тестов пройдено
```

### Тестирование групповой аналитики

```bash
python tests/test_analytics.py
```

Тест использует выборку из 6 отзывов и проверяет:

- классификацию ключевых сценариев;
- тональность;
- темы;
- количество критических случаев;
- количество эскалаций;
- корректность статистики.

Текущий результат:

```text
PASS

Групповая классификация и статистика корректны.

Всего отзывов: 6
High-criticality: 1
Эскалаций: 2
```

## 📊 Пример групповой аналитики

Для тестовой выборки ассистент способен сформировать отчёт вида:

```text
1. Объём выборки
В выборке представлено 6 отзывов.

2. Распределение по тональности
Положительные — 2 (33,3%)
Смешанные — 1 (16,7%)
Негативные — 3 (50,0%)

3. Основные темы
Товар, доставка, сервис, качество, упаковка.

4. Повторяющиеся проблемы
Проблемы качества товара и доставки.

5. Положительные тенденции
Положительная оценка товара, быстрой доставки
и работы сотрудников.

6. Критические случаи
Выявлена потенциально опасная неисправность товара.

7. Рекомендации
Обратить внимание на качество продукции,
доставку и оперативную обработку критических обращений.
```

Количественные показатели рассчитываются Python-кодом, а не генерируются моделью самостоятельно.
